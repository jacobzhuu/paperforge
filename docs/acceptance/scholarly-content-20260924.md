# 论文图表、公式与证据深度验收（2026-09-24）

## 行为变化

- 固定文献矩阵进入已有的独立证据附件，正文保留跨研究综合分析。正文主题表要求明确的比较目的、至少两项研究与共同证据维度；数值比较还要求相同的可比性键、数据集、指标、单位和划分。每表最多八项研究，每章最多两表；不选择同一研究多个设置中的“最佳”结果。
- 写作器从来源公式目录选择表达式，使用稳定的 source_id 输出独立公式、行内公式和编号引用。LaTeX 原文由程序注入，模型提供解释；未知来源或失效引用记录为质量问题。来源目录有独立预算，完整表达式不会被截断。
- PaperIR 公式增加可选来源、原始表达式和解释字段；xref 支持 equation。生成、保存、恢复、引用收集、编辑器往返、Markdown/PDF 保留这些内容。恢复时以保存的 IR 为准；已有结构化章节的普通文字润色保守跳过，避免损坏公式。
- 全文证据现在覆盖非数值的方法、定义、假设、实验设置、基线、消融和局限；字段保存原文段落而非补写事实。按内容角色与研究轮转分配写作上下文，并给公式保留位置。
- LaTeX/JATS 源文中的数学表达式保留数学边界；全文解析与写作版本已更新。不能从公式编号或失去数学结构的文本推造表达式。不增加 OCR 或原创推导。
- 只影响新生成与显式重生成；没有批量修改历史论文或历史导出。
