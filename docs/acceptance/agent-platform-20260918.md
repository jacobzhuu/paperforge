## 检索实验

3 个主题、17 个问题、5 个实验臂，共 85 次回放，本地模型付费成本 0 元。
下表的“相关”来自旧分类器生成的矩阵链接，并非人工金标；这些链接不完整且偏向原算法。
单次查询中位数混合冷暖运行，不是受控服务延迟 SLA，也不能直接作为提速结论。
