# 核心 UI/UX 优化验收（2026-09-24）

## 改动

- 保留暖白学术风与深色主题，统一页面标题、焦点反馈、窄屏按钮布局和减少动画行为。
- 首页示例追加到现有研究描述并返回输入焦点；提交期间锁定材料入口，明确提交后的研究规划流程。

- 写作页优先展示正文，插图建议移到正文之后；保留原有保存保护与增量章节更新。
- 导出页集中格式与投稿设置，折叠历史与诊断，编译失败自动展开诊断；统一按钮与空态文案。
- 导出请求防重复提交；未知质量覆盖率显示待确认，无正文时提供写作入口。
- 移动导航支持焦点循环、Escape 关闭、焦点归还、滚动锁及切换桌面宽度自动关闭。

## 公网验收中修复的首载问题

初次公网验收偶现 React #418。诊断显示客户端在核对正文节点时仍指向 head 内的 charset 元素。服务端布局从带有 `use client` 的主题组件模块导入了静态初始化脚本，RSC 将该脚本编码成异步客户端引用。

将脚本与存储键移动到不含客户端边界的 `lib/theme.ts`，服务端布局直接读取字符串，主题组件复用同一存储键。修复后确认生产 HTML/RSC 不再包含脚本的客户端引用，并重新构建、测试和部署。上述六次公网首载验证均通过。
